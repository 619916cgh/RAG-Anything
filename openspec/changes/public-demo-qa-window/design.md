## Context

现有 `/api/agents/{agent_id}/query/stream` 以登录用户、用户设置快照、KB 访问校验和 PostgreSQL 会话持久化为前提。云端演示需要复用同一检索/流式链路，同时为匿名访问建立独立的能力边界。现有 Nginx 已在同源 `/api/` 下代理 FastAPI，因此公开页不需要跨域配置。

## Goals / Non-Goals

**Goals:**
- 让超级管理员为一个固定云端智能体和知识库创建可撤销的公开演示链接。
- 在不暴露 JWT、工作区路径或永久媒体 URL 的前提下流式返回回答、引用和受控媒体。
- 对每个分享令牌施加每分钟 10 次、最多 2 个并发请求的服务端限制。
- 让演示请求不写入用户对话、消息或摘要。

**Non-Goals:**
- 不支持访客上传文件、上传提问图片、切换 KB/智能体、修改解析设置或检索参数。
- 不把普通受保护媒体或文档下载端点开放给匿名令牌。
- 不在本次变更中执行云端迁移或部署。

## Decisions

- **分享记录与令牌**：新增 `demo_shares` 表，保存 UUID 分享 ID、SHA-256 令牌哈希、固定 agent/KB、创建/撤销时间、速率窗口和并发状态。创建接口只返回一次原始令牌。选择哈希而非持久化原文，以限制数据库泄露影响。
- **URL 与认证**：公开 URL 使用 `/demo/{share_id}#<secret>`；客户端从 fragment 读取秘密并仅在 `X-Demo-Token` 中提交。选择 fragment 而非 query 参数，以避免反向代理、访问日志和 Referer 记录秘密。
- **查询执行**：将智能体流式查询的核心抽取为内部可复用函数，普通路由传入已认证用户并维持既有持久化语义；演示路由传入由分享记录派生的受限执行上下文且禁用会话写入。选择共享核心而非在 demo 路由复制长 SSE 实现，避免检索和引用语义漂移。
- **云端配置快照**：演示查询使用智能体配置的 KB、模型和检索设置，并建立稳定的公开配置指纹；不读取或模拟访客个人设置。该选择防止匿名请求访问用户私有设置，同时保持固定演示行为。
- **媒体**：SSE 中的媒体元数据保持无路径；公开媒体端点验证分享令牌、分享绑定 KB 和媒体 ID，然后返回短时签名的受控 URL 或直接受控响应。选择单独端点而非复用登录媒体 URL，避免令牌能力混淆。
- **前端**：在 App 的认证驾驶舱分支外渲染 `/demo/:shareId`，使用独立 API 辅助函数和 kiosk 布局。页面仅显示 bootstrap 允许的名称、入库默认解析/分块摘要以及回答事件。

## Risks / Trade-offs

- [长期链接泄露] → 仅存哈希、提供立即撤销、令牌级限流和并发限制；云端运营方仍应在展示结束后撤销链接。
- [共享查询逻辑回归] → 将普通和演示执行模式以显式上下文区分，并补充普通路由回归测试。
- [媒体越权] → 公开端点只从分享绑定 KB 的媒体目录解析 ID，禁止文件路径和常规下载 URL。
- [内存限流在多进程不一致] → 速率/并发状态存储在 PostgreSQL；部署前在真实多进程环境验证。
- [云端验收不可在本地替代] → 将真实 PostgreSQL、Nginx、SSE、引用与媒体 smoke 列为部署后门槛。

## Migration Plan

1. 在受控 PostgreSQL 备份已验证后，使用迁移清单执行新增迁移并核验 repeat/rollback 策略。
2. 发布应用和前端镜像，确认 Nginx 将 `/demo/*` 回退到 SPA、`/api/demo/*` 转发至应用。
3. 由超级管理员创建测试分享，使用真实云端 KB 验证问答、引用、媒体、限流和撤销。
4. 若需回滚，先撤销所有分享，再回滚应用版本；迁移保留表和令牌哈希，不在未审计的数据删除前执行破坏性 DDL。

## Open Questions

- 无。链接长期有效、仅超级管理员管理、固定一个智能体/知识库、仅令牌级限流和不保存会话均由已批准计划确定。
