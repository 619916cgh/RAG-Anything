## Why

云端知识库需要一个可用于现场演示的独立问答入口。现有智能体问答依赖登录用户、RBAC 和持久化会话，不能安全地直接暴露给匿名访客，也不能让前端自行选择任意知识库。

## What Changes

- 新增由超级管理员创建、复制和撤销的公开演示分享链接，每条链接固定一个云端智能体及其绑定知识库。
- 新增同源匿名 bootstrap、流式问答和受控媒体预览 API；令牌仅以哈希形式持久化，浏览器通过请求头提交 URL fragment 中的秘密。
- 复用现有 RAG 查询和 SSE 事件语义，但演示请求不创建对话、消息或摘要记录，并在请求期间执行分享级限流和撤销校验。
- 新增不带管理壳的 `/demo/{share_id}` 问答界面，显示回答、引用、受控媒体和知识库的只读入库默认信息。
- 将公开演示页与 API 随现有同源 Nginx/Docker 应用发布；不引入浏览器侧数据库、凭据或跨域访问。
- 在实现和验证完成后同步 `PROJECT_SUMMARY.md`。

## Capabilities

### New Capabilities
- `public-demo-qa`: 为固定云端智能体和知识库提供可撤销、限流、无会话持久化的公开问答及受控媒体预览。

### Modified Capabilities
- `citation-frontend-display`: 公开演示页面以受控预览取代登录用户的本地打开和原文上下文跳转行为。

## Impact

- 影响 FastAPI 路由、查询执行复用层、PostgreSQL 迁移与迁移清单、媒体访问控制、超级管理员 UI、React 路由和前端 SSE 客户端。
- 云端部署需要在已验证 PostgreSQL 备份后执行迁移，并重建应用和前端镜像；本地测试不构成云端知识库或生产发布验收。
