# 附录 B： 软件说明书

糖尿病视网膜病变快速筛查工具使用说明

- 1 软件概述

本软件为“基于深度学习的糖尿病视网膜病变智能筛查系统”，是一款面向基层医疗机构的轻 量级眼底图像辅助诊断工具。系统以 MobileNetV3 轻量级卷积神经网络为核心推理引擎，结合 Flask Web 框架搭建 B/S 架构，用户通过浏览器即可完成眼底图像上传、自动筛查、病变分级及历史记录 管理，无需安装客户端软件。

- 1.1 功能

- （1）用户权限管理：支持用户注册、登录与密码修改，区分管理员与普通用户两种角色，实现数据 权限隔离。
- （2）眼底图像筛查：支持单张与批量（单次最多 50 张）眼底图像上传，兼容 JPG、JPEG、PNG 格 式，自动完成图像预处理、模型推理与结果输出。
- （3）筛查结果展示：输出正常或糖尿病视网膜病变的二分类结果，显示预测置信度，并基于置信度 进行病变程度分级（初期、中期、晚期），同步给出对应医学建议。
- （4）历史记录管理：自动保存每次筛查记录，支持历史查询、追溯与 CSV 格式导出，方便数据统 计与复诊参考。
- （5）系统后台管理：管理员可进行用户管理、全量筛查记录检索与删除，以及系统数据文件的统一 维护。


- 1.2 原理


本系统基于深度学习技术实现眼底图像的自动化分类。算法层面，以 MobileNetV3-Large 为骨 干网络，采用深度可分离卷积与 SE 通道注意力机制，结合 ImageNet 预训练权重进行迁移学习，在 自建的二分类眼底图像数据集上完成模型微调。系统部署时，用户上传眼底图像后，后端调用 PyTorch 加载训练好的模型权重进行前向推理，输出诊断结论、置信度与病变等级，并将结果返回前端展示。

- 2 软件安装


- 2.1 系统要求

- (1) 操作系统 ：Windows 10/11、Linux（Ubuntu 18.04+）、macOS 10.14+
- (2) Python 版本 ：Python 3.11
- (3) 内存要求 ：至少 8GB RAM，推荐 16GB 以上
- (4) GPU 支持 ：可选，支持 NVIDIA GPU（CUDA 11.0+）可提升检测速度
- (5) 存储空间 ：至少 2GB 可用空间。


- 2.2 安装前的准备

- (1) 确保已安装 Python 3.10 及以上版本
- (2) 安装 Git 工具（可选，用于克隆项目）
- (3) 如使用 GPU 加速，需提前安装 CUDA 和 cuDNN。


- 2.3 安装

- (1) 解压项目文件到本地目录，如 C:\Users\98014\mobilenet
- (2) 打开命令行终端，进入项目目录
- (3) 安装依赖库：pip install -r requirements.txt
- (4) 确保模型权重文件 MobileNetV3.pth 已存在于项目根目录。


- 2.4 安装后


- (1) 验证安装：运行 python model_analysis.py 检查模型是否正常加载
- (2) 首次运行 Web 服务时，系统会自动创建用户数据文件和结果存储目录
- (3) 默认管理员账户：用户名 root ，密码 root。
