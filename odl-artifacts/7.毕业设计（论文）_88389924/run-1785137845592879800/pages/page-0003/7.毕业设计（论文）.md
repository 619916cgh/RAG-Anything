# 摘 要

糖尿病视网膜病变（DR）是糖尿病引起的一种严重微血管并发症，也是导致成年 人不可逆视力损害的主要原因之一。传统的 DR 筛查高度依赖眼科医生对眼底彩照的人 工判读，这种方式不仅效率低、成本高，而且主观判断差异大，尤其在基层医疗资源分 布不均的情况下，实际推广困难重重。围绕这些现实问题，本研究基于深度学习技术， 设计并实现了一套面向基层医疗机构的轻量级糖尿病视网膜病变智能筛查系统。

本文基于包含 4481 张眼底照片的大规模数据集建立一个用于二分类问题的深度学 习方法。其中正常与异常样本的数量大致是 67.57%和 32.43%，说明数据非常不平衡。 为了提高模型鲁棒性和泛化能力，于是基于原始数据集做了随机裁剪、镜像翻转及归一 化等一系列增强操作。采用 MobileNetV3-Large 作为基础网络模型并利用 ImageNet 上的 预训练权重对其进行特征提取。此外还加入了批归一化层、余弦退火的学习率调整方式 和Adam 优化方法等重要部分来进一步优化模型参数和结构。经过多次训练和测试之后， 得到的效果良好：在单独的测试集上获得总体准确率为 81.44%、精确率为 83.53%、召 回率为 81.44%和 F1 得分为 81.85%，准确率相比于基线提高了约 9.04 个百分点。根据 实际情况，此方案可以做到一张图只需花费 26 毫秒就可进行预测，同时还具有较小的 参数量（约为 4.2 百万）以及较低的内存消耗（约为 16.23MB），这就很好地兼顾了精 度和速度的关系。

本系统以 PyTorch 深度学习框架以及 Flask 微服务框架为基础构建，在 B/S 架构下 实现前端与后端分离。主要实现内容有多层次用户权限管理（管理员和普通用户的区别）、 多张眼底图像智能化分析、依据置信度评估病灶进展程度（分为早期、中期和晚期）、 查询以往筛查结果以及对数据库进行维护等功能。

关键词：深度学习；眼底识别；MobileNetV3；图片分类；糖尿病视网膜病变
