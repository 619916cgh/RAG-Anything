处理上通过 UUID 为每个文件命名来防止重复上传，同时用 secure_filename 剔除一些不 允许出现的字符保证服务器的安全性。对于结果输出是以 JSON 格式返回给前端方便其 解析显示，而筛查记录保存到 CSV 中形成有据可查的日志。

首先验证用户登录情况以及上传文件合法性，然后判断文件类型是否符合要求，之 后使用 UUID 给文件命名并且存储到服务器上，然后对这张图片进行预处理后利用 MobileNetV3 进行预测，得到结果、概率以及病灶级别，紧接着根据医学建议字典得出 最终诊断结果及建议，最后将检测信息存入 CSV 文件并通过 JSON 形式发送给前端显 示。

# 6.3 批量图像筛查模块

批量图像筛查模块是为帮助用户一次性上传多张眼底图像进行集中筛查而设计，可 以大大提高大批量筛查的工作效率，在后端使用 Flask 接收前端上传的批量图像文件， 然后一张张地对这些图片进行合法性的检查、存储以及预处理，之后依次使用 MobileNetV3 模型完成对它们的识别和判断，得到每个图片所对应的诊断结果、置信度 以及疾病级别以及相应的治疗意见。所有图片筛查完成后，模块会对整个批次的结果做 一个总的统计，包括正常数量和其他各种疾病的数量。批量筛查可以一次处理多个图片， 而且流程完全自动化，有利于在基层医疗机构中大幅度提高筛查速度。如图 26 所示。
