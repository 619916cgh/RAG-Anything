# 3.3 可行性分析

- 3.3.1 技术可行性 算法方面。MobileNetV3 是成熟的轻量化模型，参数少、推理速度快，在此基础上

使用迁移学习可以很快进行训练，技术成熟可靠。

开发层面。PyTorch 框架支持模型训练与推理，Flask 轻量级 Web 框架易上手、开 发周期短，B/S 架构无需客户端安装，部署便捷。

工具层面。数据增强、图像预处理、前后端交互均有成熟开源工具与代码库支撑， 简单易实现。

- 3.3.2 经济可行性 开发过程中使用开源框架及工具，无须支付软件版权费用；对于硬件要求较低，一

般服务器或者电脑都可以进行安装以及运行，不需要较高配置硬件设备。系统上线之后 可以取代人工初筛工作，有利于减少基层医疗卫生机构人力支出，具有较高的性价比。

- 3.3.3 操作可行性 系统使用 Web 网页的形式，用户利用浏览器可以方便地进行访问，不需要下载任

何插件或程序，十分便捷，而且整个过程只有上传图片、查看结果以及查询历史这 3 个 步骤，有明确的操作说明以及结果的解释，尽可能让用户能够理解。

统运行效率、安全性基础上确定系统的范围；并从技术上、经济上以及实现难度上来说 明该系统的可行性，表明该项目可以进行下去。
