# 致谢

时间如白驹过隙，转眼间，四年的大学生活即将结束，当我在完成整个系统的设计

与论文的编写，回望这篇毕业设计的整个过程，从选题时的迷茫，到研究中遇到的问题， 再到最后形成一个完整的体系，这一切，都离不开老师、同学们以及家人的帮助和支持。

首先，我要真诚地向我的导师邱保志教授表示感谢，在选题、方案制定以及论文写 作的过程中，导师都给了我很大的帮助和支持，在我遇到 MobileNetV3 模型优化问题、 Flask 系统架构设计或者代码调试困难时，导师都会及时给我指明方向并给予鼓励，让 我茅塞顿开，勇往直前，这都是我永远难忘的。

其次，感谢身边同学和朋友。论文撰写以及系统实现过程中，我得到了很大的支持。 遇到问题时，同学之间沟通启发我思考，也帮助我解决一些有关数据集以及 Web 系统 部署方面问题。大学四年，因有你们而精彩，也有了许多美好记忆。

也特别感谢我的家人，你们一直是我坚实的后盾，在我遇到困难时给予我理解、支 持及无私的帮助使我安心的学习。

最后，对一直以来关心、支持我的师长、同事、朋友们以及家人们表示衷心感谢。
