- （1） 前端层。采用 HTML5 + CSS3 + JavaScript 构建简洁的 Web 操作界面，支持

图片上传、结果展示、历史记录查询、批量筛查等交互功能，采用响应式布局，适配电 脑端浏览器访问。

- （2） 后端服务层。使用 Flask 轻量级 Web 框架提供接口服务。负责用户登录验证、

图片接收、模型推理、结果存储与返回，支持高并发、多用户同时访问。

- （3） 模型推理层。基于 PyTorch 深度学习框架加载 MobileNetV3 预训练权重。完

成眼底图像预处理、特征提取、病变分类与置信度计算，输出分类结果、置信度、病变 等级与诊疗建议。

- （4） 数据存储层。采用文件型数据库形式：JSON 存储用户信息、CSV 存储筛查


记录。不使用独立数据库服务，部署简单、迁移方便。

- 4.1.2 技术栈选型 开发语言：Python 3.8+ Web 框架：Flask 2.0+ 深度学习框架：PyTorch 1.10+ 数据处理：Pandas、NumPy、Transform 模型：MobileNetV3-Large 存储：users.json、results.csv、本地上传文件夹 uploads
