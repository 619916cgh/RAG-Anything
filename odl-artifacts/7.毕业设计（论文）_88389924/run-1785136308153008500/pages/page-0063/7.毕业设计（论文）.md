# 3 运行说明

- (1) 启动 Web 服务。
- (2) 在命令行终端执行：python model_analysis.py。
- (3) 服务启动后，在浏览器中访问 http://localhost:8000 访问系统首页。
- (4) 首次使用可点击"注册"创建账户，或使用默认管理员账户登录。
- (5) 输入用户名和密码，点击"登录"进入系统。
- (6) 点击左侧菜单"单张检测"，点击上传区域选择眼底照片（支持 jpg、jpeg、png 格式）。
- (7) 等待系统分析，显示诊断结果、置信度和健康建议。
- (8) 点击左侧菜单"批量检测"，选择多张眼底照片（最多 50 张）系统逐一分析并展示批量检测
- (9) 点击左侧菜单"历史记录"。
- (10) 查看所有检测记录，支持删除操作。
- (11) 管理员可查看所有用户的检测记录。
- (12) 在命令行终端执行：python model_analysis.py，分析报告将保存到 results/model_analysis_report.txt。


# 4 疑难解答

- (1) 问题 1：启动服务时提示缺少依赖库。解决方案：运行 pip install -r requirements.txt 安装所 有依赖。
- (2) 问题 2：上传图片后无法识别。解决方案：确保图片格式为 jpg、jpeg 或 png，文件大小不超 过 16MB。
- (3) 问题 3：检测结果置信度较低。解决方案：确保上传的眼底照片清晰，光线充足，瞳孔居中。
- (4) 问题 4：GPU 加速未生效。解决方案：检查 CUDA 环境是否正确配置，确保 PyTorch 支持 CUDA。
- (5) 问题 5：登录失败。解决方案：确认用户名和密码正确，首次使用可使用默认账户 root/root
- (6) 错误日志。系统运行日志保存在 app.log 文件中，可查看详细错误信息。
