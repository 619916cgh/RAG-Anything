# 6.2 单张图像筛查模块

单张图像筛查模块是整个系统的主识别功能，基于 Flask 后端接口开发完成，用于 接收用户上传一张眼底照片并进行智能化筛查。用户在前端页面上选取.jpg/.jpeg/.png 类 型的眼底照片之后，在服务器端对用户的登录情况以及文件合法性进行检查，检查成功 后将这张图片使用一个唯一的文件名保存在 uploads 文件夹下，然后调用 predict.py 中预 测接口，对这张图片进行预处理后利用 MobileNetV3 模型进行推理计算出疾病类别、概 率及严重程度，根据此给出相应医疗建议，最后把此次筛查的信息写入 results.csv 文件 并且将识别的结果以及图片一起以 JSON 形式返回给前端显示。该模块实现了从接收图 片、智能识别、得出结论以及保存整个过程自动化，简单方便、快速高效，可以供一个 人完成快速筛查工作，如图 25 所示。
