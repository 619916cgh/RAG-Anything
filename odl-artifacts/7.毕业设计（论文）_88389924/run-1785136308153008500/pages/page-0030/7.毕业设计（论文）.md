# 5.2 模型选型

在除本系统所用的 MobileNetV3 模型以外，EfficientNet 模型也比较适配本系统，所 以选择使用相同的模型参数将 MobileNetV3 与 EfficientNet 分别进行模型训练。

- 5.2.1 技术原理对比 EfficientNet 模型与 MobileNetV3 模型技术上的对比如表 6 所示。

表 6 两种模型技术对比表 技术特性 EfficientNet MobileNetV3 网络设计 复合缩放策略 深度可分离卷积 + 反转残差结构 激活函数 Swish h-swish

注意力机制 SE 模块 SE 模块 + 更轻量级的注意力设计 计算复杂度 高 低

内存访问成本 高 低

从上表可以看出，EfficientNet 和 MobileNetV3 在设计理念上存在较大差异， EfficientNet 是以复合缩放为基础的思想，在增加网络宽度、深度以及输入尺寸的同时提 高模型的效果，但是这样也会导致更大的计算量以及更高的内存需求；而 MobileNetV3 则是利用深度可分离卷积以及倒残差结构，运用 h-swish 等高效激活函数以及轻量化注 意力机制，虽然牺牲一部分特征学习的能力但是极大地减少了参数量以及计算量。
