# 1 绪 论

## 1.1 研究背景与意义

糖尿病是一种严重影响公共健康的慢性病，其患病率逐年升高并带来诸多不良后果，

而糖尿病视网膜病变（Diabetic Retinopathy, DR）是成年人致盲的重要因素之一。据世 界卫生组织报道，目前全世界糖尿病患者达到 5 亿人以上并且还在不断增加，在所有糖 尿病患者当中有大约三分之一的人会在一定时间内发生不同程度的 DR 症状；如果这些 患者得不到适当有效的干预，则有可能发展成为增殖性糖尿病视网膜病变（Proliferative Diabetic Retinopathy, PDR），从而出现视网膜新生血管化、玻璃体积血以及牵拉性视网 膜脱离等问题，最终造成不可恢复的视力下降甚至完全丧失视力。因此，制定一个标准 化、普及性和前瞻性良好的早期筛查方法迫在眉睫，这不仅有助于减慢疾病的进程而且 还可以保护患者的视力以及提高他们的生活质量。

目前糖尿病视网膜病变（DR）的临床诊断主要是由眼科医生根据眼底照片进行人 工判读。这种方式有以下缺点：一，每个人的认识水平以及经验不同，因此不同的医生 对于疾病的分期以及严重程度可能会有不同的看法；二，长期的工作容易造成眼睛疲劳， 进而影响到诊断的效果；三，在庞大的糖尿病人群中，现在的人工筛查由于其低效并且 需要较多的人力资源而无法做到全覆盖。为了克服这些问题，就需要使用智能化的方法 来解决人力不足的问题，提高工作效率，实现 DR 筛查的规范化、规模化以及精准化。

近年来，随着深度学习技术在医学影像分析方面取得重大进展，糖尿病视网膜病变 （Diabetic Retinopathy, DR）智能筛查成为可能。而 MobileNetV3 是轻量化卷积神经网 络的一种，由于其简洁的设计、小的参数量以及快的速度，在保持较高准确率的基础上 具备良好的鲁棒性，十分适合应用于移动设备、乡镇卫生院或者远程医疗等对于计算能 力要求低的应用场景。基于此平台搭建的 DR 智能检测系统可以迅速地对眼底图片进行 分析并准确判断疾病严重程度，从而解决普通人无法及时发现的问题。此方法大大提高 了筛查速度及覆盖面，也一定程度上缓解了医疗资源分配不合理问题，使优质的医疗服 务更加普及。这主要是为了满足医生的需求同时也对提高国民健康水平以及完善国民健 康服务起到积极作用。
