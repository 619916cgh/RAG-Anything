# 4.4 本章小结

本章完成整个系统的设计工作，以 B/S 前后端分离的设计方式，分为前端展示层、 后端服务层、模型推理层以及数据存储层四个部分，使用的主要技术有 Python、Flask、

PyTorch 等，推理模型选择 MobileNetV3-Large，数据保存采用轻量级的 JSON 和 CSV 文件格式。系统分为用户权限管理、单张或者多张图片检测、结果显示及建议、历史记 录查询以及系统管理六个部分并对其各自的职责进行了详细的描述，这既满足系统的功 能性要求也考虑到了基层部署的轻便性，对接下来的工作开展起到指导作用。
